# Human Resources Dashboard (Tableau)

## Overview
This project is an **interactive HR analytics dashboard** built in **Tableau**, using a simulated dataset of **8,950 employees**.  
The dashboard provides insights into demographics, salaries, job roles, performance ratings, and attrition patterns, enabling exploration of key HR metrics for workforce analysis and decision-making.

---

## Contents
- **Dataset:** `HumanResources.csv` (synthetic HR records)  
- **Tableau Dashboard:** Interactive visualization with filters and calculated fields  
- **Mockups/Designs:** Reference layouts created before building in Tableau  

---

## Features
- **Demographics:** Visualizes employee distribution by age, gender, education, and location.  
- **Job Details:** Displays departmental composition, job titles, hire/termination timelines, and performance ratings.  
- **Compensation:** Compares salary distributions across departments, job levels, and demographics.  
- **Attrition Analysis:** Highlights turnover trends and identifies high-risk employee groups.  
- **Interactive Views:** Includes filters, drill-downs, and calculated fields for deeper, self-service analysis.  

---

## How to Use
1. Download the dataset (`HumanResources.csv`).  
2. Open Tableau Desktop or Tableau Public.  
3. Connect Tableau to the dataset.  
4. Explore the dashboard using interactive filters, tooltips, and data highlights.  

---

## Insights and Applications
- Identified patterns in **employee attrition** related to job satisfaction, salary, and tenure.  
- Analyzed **salary equity** across gender and department groups.  
- Monitored **departmental performance trends** and workforce distribution over time.  
- Supported **data-driven HR decision-making** for recruitment, retention, and compensation strategies.
